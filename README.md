# SERVERLESS-E-LEARNING-APPLICATION-USING-GENERATIVE-AI-AND-AWS-BEDROCK
Developed a serverless e-learning platform using AWS Bedrock and Generative AI to deliver personalized learning content, AI-powered Q&amp;A, and study recommendations. Leveraged AWS Lambda, API Gateway, S3, and DynamoDB for scalable, cost-effective, and efficient cloud-based learning.
